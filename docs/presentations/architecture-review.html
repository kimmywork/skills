Architecture decision review · fictional case

Streaming event ingestion at Meridian

From nightly batch to a six-hour freshness target

Decision requested: approve phase 1 · 2026

Context

2.4B events/day, six-hour freshness, and a batch window that no longer fits

Volume

2.4B events/day, 3.1× year over year.

Freshness

Product needs six hours; batch gives 24.

Pressure

The nightly window now overlaps peak ingest.

Requirements

What any option must satisfy

Correctness

Exactly-once semantics at the sink; idempotent replay.

Replay

90-day replay for backfill and incident recovery.

Cost

≤ 1.4× current run rate at 3× volume.

Migration

No customer-visible cutover; rollback in one hour.

Options

Three credible paths

OptionShapeStrengthWeakness
A · Batch + micro-batchKeep batch, add 15-min micro-batchesLowest migration riskCannot reach 6h freshness at peak
B · Kafka + FlinkStreaming ingest, managed Kafka, Flink jobsMeets freshness and replayOperational load; new on-call surface
C · Managed ingestionVendor-managed pipelineLowest opsCost and lock-in at 3× volume

Trade-offs

B wins on the requirements; the cost is operational

CriterionABC
Six-hour freshnessNoYesYes
90-day replayPartialYesVendor-dependent
Cost at 3×LowMediumHigh
Operational loadLowHighLow
Migration riskLowMediumMedium

Recommendation

Adopt B, phased, with batch retained for backfill.

Managed Kafka for ingest, Flink for exactly-once aggregation, and a one-hour rollback to the batch path.

Migration

Four phases, one rollback point

P1Dual-write to Kafka and batch; compare counts.
P2Shadow-read from streaming; reconcile 30 days.
P3Cut over product reads; batch becomes backfill.
P4Decommission batch ingest after two clean weeks.

Risks

What could break, and the mitigation

Ordering

Partition key change can reorder events; freeze the key at P2.

Schema evolution

Registry compatibility mode; reject breaking changes in CI.

Cost spike

Per-tenant quotas; weekly cost review during P1–P3.

On-call load

Two engineers trained before cutover; runbook and game day.

Decision

Approve phase 1

Success criteria: 6-hour freshness at 3× volume, 99.95% sink availability, one-hour rollback proven in a game day.

Next review: end of phase 2 · Q&A follows
