Root cause

A config flag mismatch, amplified by a retry storm

Trigger

4.18.0 changed the retry budget from 3 to 8 but left the payment gateway flag at the old ceiling.

Amplifier

Failed authorizations retried immediately; the gateway throttled the whole merchant account, not the single route.

Not a single bug. A deploy-safety gap let an inconsistent configuration reach 100% of traffic.

Contributing factors

What made it possible

Canary too small

2% of traffic for 4 minutes could not surface a gateway-wide throttle.

No synthetic checkout

Health checks covered the API, not the checkout path.

Runbook stale

The rollback step referenced the old deployment tool.

Handoff gap

The on-call handoff missed the deploy note by 12 minutes.

What went well

Recovery was faster because the basics held

Rollback

One command; no schema change. The last known-good artifact was available.

Status page updated at 09:26; support had a script by 09:32.

The lesson

Deploy safety is a product, not a checklist.

The system allowed an inconsistent configuration to reach all traffic. Fix the system, not the deploy that exposed it.
