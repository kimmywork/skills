What it proves

Different rooms, same discipline.

The deck changes; the standards do not. These cases cover evidence, persuasion, learning, governance, demo, and craft.

EvidenceAcademic

Defend a claim, not a method

One question, two results, explicit limits, and a recommendation the committee can act on.

PersuasionPitch

Make the ask inevitable

Bottom-up market, traction, a business model, and a specific ask — one number per slide.

LearningPostmortem

Learn without blaming

Impact, timeline, trigger, amplifier, actions with owners, and a systemic lesson.

DecisionArchitecture

Make the trade-off explicit

Options, criteria, a recommendation, a migration plan, and a rollback the board can trust.

StoryKeynote

One idea, one action

A hook, a single idea, three pieces of evidence, three practices, and a close that lands.

TeachingWorkshop

Make the room do the work

Objective, warm-up, concept, example, two exercises, share, and three rules to take back.

GovernanceBusiness review

Surface the variance

Headline, KPI table, drivers, actions, and three asks with owners and dates.

LaunchProduct

Demo the value, not the features

Problem, insight, three-scene demo, pilot evidence, availability, one CTA.

Production loop

Built like a deck, not a document.

The same loop the presentation skill asks for: fix the stage, settle one sample, write in batches, check a contact sheet, and keep one source for the notes and the time budget.

1 · Stage + tokens16:9, type scale, color roles, safe margins.
2 · Skeleton + sampleOne slide proves the layout before thirty follow.
3 · Section dataTitle, budget, notes; generate counter and notes.
4 · Contact sheetBatch screenshots; inspect the sheet, then the page.
5 · Assets + factsOfficial source first; comparison matches the claim.
