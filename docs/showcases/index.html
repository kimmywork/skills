One skill, two directions

Build the system.
Judge the experience.

The same standards govern both. System work produces tokens, scenes, and a drift check. Review work produces an evidence-graded issue register, a fix plan, and guard rules.

01 · SYSTEM

Make it coherent.

Extract, rebuild, greenfield, or govern. The system is the source of truth; the showcase proves it.

ExtractRebuildGreenfieldGovern
Output · showcase · specification · drift check
02 · REVIEW

Make it honest.

Review a product, an artifact, or the system itself. Evidence over taste; protect what works; prioritize what changes the decision.

ProductArtifactSystem
Output · review report · issue register · fix plan · guard rules
Evidence over inventionRead the real source. Quote the value. Mark what is designed.
Reasoning is traceableStance → principle → rule → token → check. No orphan decisions.
Accessibility is a foundationContrast, focus, targets, motion, and assistive tech are part of the system.
Adopt before inventingUse a mature convention when it fits, and record every deviation.
