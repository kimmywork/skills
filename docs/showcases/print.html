fieldstation — fixed canvas, no interaction, still a system

A research lab's poster and report language. The canvas is fixed, so “states” become page types and data extremes; color is a print decision measured in CMYK assumptions; hierarchy must survive grayscale and distance. Whole pages at true proportion replace component samplers.

A2 poster · A4 report typographic grid + measure grayscale proof print color values tagged structure

Context

Who: researchers presenting at a conference and readers of the printed report. Jobs: read the argument from two meters (poster) and from arm's length (report); cite and archive the PDF. Constraints: one fixed canvas, no hover or focus, no reflow, a print pipeline that flattens transparency and converts color. One system covers both formats through a shared grid, type scale, and ink palette.

Interaction, motion, accessibility

No interaction and no motion — by design

  • Interaction states — hover, focus, press, and disabled do not exist on paper. Their equivalent is the page-type grammar: a reader can tell cover, body, figure, and table apart at a glance, and clear cross-references replace affordances.
  • Motion — none. The artifact does not move; page-turn and reveal behavior belongs to the reader or the PDF viewer, never to the design.
  • States become page types and extremes — cover, body, full-bleed figure, table, colophon; a 140-character title wraps to three lines; an empty table cell shows an em dash; a wide table moves to a landscape page rather than compressing.
  • Reading order — tagged structure defines the order a screen reader and the PDF export will follow: title, authors, abstract, sections, captions, footnotes.

Accessibility

  • Every figure carries alternative text and a caption that states the takeaway, not only the axes.
  • Ink-on-paper contrast is measured for the actual paper stock; body text stays below the 80% tint line at text sizes.
  • The PDF export preserves tags, reading order, and document language.

Verification

  • Grayscale proof: switch the proof above and confirm hierarchy and the figure remain readable without color.
  • Grid overlay: confirm every page shares one grid and one margin; text never enters the trim.
  • Print values: every token lists hex and naive CMYK; the printer's profile is declared in the colophon.
  • Proportion: sheets render at true aspect ratio, so a wrong canvas is visible immediately.
