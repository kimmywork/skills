design-system · example outputs

Eight systems, eight surfaces, eight self-contained proofs

Each case is a showcase artifact produced by the design-system skill for a different surface class: terminal, CLI, mobile app, four game genres, and print. Every page is a single HTML file, obeys its own system, and renders its whole-use scenes on the target canvas — not a component sampler.

The gallery never injects a theme into the cases; a surface's system is isolated, and only vocabulary is shared. Game and document cases load webfonts from Google Fonts to demonstrate their type registers, and fall back to system faces offline; everything else is inline. Open a case directly to see its own controls, token tables, and verification probes.
