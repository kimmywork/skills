# Visual and Accessibility

Read this when the content is ready to be seen. Projection and paper are different media; both must survive the room, the page, and grayscale. Treat the values here as constraints and starting points, not universal constants: the right grid, type scale, density, and tone depend on the topic, setting, audience, and medium.

## Projection

- Use 16:9 unless the venue says otherwise; keep a safe margin for overscan.
- One idea per slide. If a slide argues two things, split it.
- Set a type scale for the back of the room, not for the laptop. Body text is large; captions are not an excuse for small text.
- Contrast at least 4.5:1 for normal text and 3:1 for large text. Thin weights lose contrast; use regular or medium.
- A grid and consistent margins; no element touches the edge.
- Motion explains change or directs attention; it never delays or decorates.

## Page and print

- One grid, one reading measure, one hierarchy across pages.
- Size and weight carry hierarchy before color.
- Number and reference every figure and table in the text.
- A4 or Letter margins; no text in trim or fold zones.
- The document must read in grayscale; color is secondary.

## Data

- State axis, baseline, source, sample, and units.
- No truncated axes, no 3D, no chartjunk.
- Use the chart that makes the point; a table is often better than a weak chart.
- Changing values use tabular numerals.
- Never use color as the only encoding; add labels, shape, or pattern.

## Accessibility

- Alt text for every meaningful image; mark decorative images as decorative.
- Reading order follows the argument, not the layout.
- Captions or a transcript for video and audio.
- Color never carries meaning alone.
- Respect reduced motion.
- Plain language; define terms; avoid unexplained acronyms.
- A handout that works without the speaker.

## Verification

Render every slide or page. Batch screenshots and a contact sheet first; inspect individual slides only after the sheet. Check at presentation size and at reading size; check in grayscale; check the printed sheet; check the offline file; check that the source outline and the artifact agree. Fix what fails before delivery.

## Anti-patterns

- Tiny text to fit more content.
- Decoration that competes with the evidence.
- A chart without a source or a baseline.
- A slide that only makes sense while someone talks.
- A document that is unreadable in grayscale or print.
